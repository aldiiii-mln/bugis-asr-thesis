# Automatic Speech Recognition for the Low-Resource Bugis Language

Undergraduate thesis project (Universiti Teknikal Malaysia Melaka / UTeM) evaluating 
authentic-synthetic data combination for ASR on Whisper, OWSM, and MMS, applied to 
Bugis — a low-resource Austronesian language spoken in South Sulawesi, Indonesia.

## Overview
This project fine-tunes and evaluates three ASR architectures under three data 
conditions (Authentic-Only, Synthetic-Only, Combined) to study whether combining 
authentic speech with synthetic (TTS) data improves generalization to real Bugis 
speech, compared to either data source alone.

## Data Sources
- Authentic speech: Global Recordings Network (GRN), Bugis
- Synthetic speech: Edge TTS (Indonesian voice reading Bugis text)
- Bible text/audio: LAIBUG (Today's Bugis Version, 1997, Indonesian Bible Society), 
  audio by Davar Partners International — used for domain-matched authentic corpus 
  expansion, via the Bible Brain API (Faith Comes By Hearing)
